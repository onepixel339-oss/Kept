# Kept — تطبيق الذاكرة الشخصية

تطبيق ويب لحفظ الذكريات الشخصية وتنظيمها: كتابة، رفع صور وصوتيات ومستندات، بحث
دقيق وزمني، كيانات وعلاقات (ناس ومواضيع)، ومحادثة تحقق تجيب من ذاكرتك أنت فقط —
بإجابات مسندة للمصدر وحدود صادقة عندما لا يوجد دليل.

- **البناء**: Next.js 16 + React 19 + TypeScript + Tailwind + shadcn/ui
- **قاعدة البيانات**: PostgreSQL (Supabase) عبر Prisma — مخطط قابل للترحيل منذ اليوم الأول
- **التخزين**: Supabase Storage (باكت خاص، وصول عبر مسارات مصرّح بها فقط)
- **الحسابات**: تسجيل/دخول بكلمة مرور (scrypt + جلسات مبهمة)، تصدير وحذف حقيقي

## النشر على Vercel

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. في Supabase استرجع قيم الاتصال (الشرح التفصيلي: `DEPLOY-GUIDE.txt`).
3. استورد المستودع في Vercel وأضف متغيرات البيئة:

| المتغير | الدور |
|---|---|
| `DATABASE_URL` | اتصال التشغيل — Transaction Pooler (6543) |
| `DIRECT_URL` | اتصال الهجرات — Direct (5432) |
| `SUPABASE_URL` | عنوان المشروع من Settings ← API |
| `SUPABASE_SECRET_KEY` | مفتاح الخدمة `sb_secret_…` (سري — سيرفر فقط) |
| `KEPT_IDENTITY_SECRET` | قيمة عشوائية ثابتة تولّدها مرة واحدة |

4. اضغط Deploy — أمر البناء مضبوط مسبقًا في `vercel.json`
   (`npx prisma generate && npm run build`)، ووضع التخزين ينتقل تلقائيًا
   إلى Supabase عند وجود متغيرات Supabase.

> ملاحظة أمان: لا تضع قيمًا حقيقية في `.env.example` ولا ترفع ملف `.env` أبدًا.

## التطوير المحلي

```bash
npm install
npx prisma generate
cp .env.example .env   # ثم عدّل القيم لبيئة التطوير
npm run dev
```
